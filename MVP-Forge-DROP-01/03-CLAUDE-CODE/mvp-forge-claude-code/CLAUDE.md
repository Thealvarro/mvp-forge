# MVP Forge — Builder Edition

Esta carpeta define un MVP antes de programarlo.

Para empezar, el usuario ejecuta `/crear-proyecto`. Esa Skill lleva una entrevista adaptativa de 9 etapas y al final escribe la documentación en `proyecto/`.

Reglas de esta carpeta:

- No programes la aplicación antes de que la definición esté cerrada y los documentos generados.
- Aplica FREE-FIRST: prioriza herramientas gratuitas o free tier, y explica costo y límites antes de recomendar.
- Controla el alcance. Separa siempre V1 imprescindible / Después de validar / Futuro.
- Si el proyecto toca cuentas, datos personales o pagos: reglas de acceso en la base de datos, validación en el servidor y secretos fuera del frontend.

Una vez que exista `proyecto/`, esa documentación manda: léela antes de construir.
